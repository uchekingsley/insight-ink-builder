# Miracle's Portfolio Hub

# Portfolio Build Instructions

## Project Overview

Build two connected deliverables from the same content:

1. A responsive portfolio website. This will serve as the primary portfolio.
2. A professionally designed PDF portfolio generated from the same content for job applications and recruiter sharing.

Both versions must maintain consistent branding, content, and structure. The website should be the complete portfolio, while the PDF should be a concise version optimized for recruiters.

The website should be fully responsive across desktop, tablet, and mobile devices.

The PDF should be clean, professional, easy to read on screen and in print, and suitable for attaching to internship and job applications.

# RECOMMENDED BUILD ORDER

1. Finalize all written content before beginning design.

2. Design and build the PDF portfolio first so there is a professional document ready for applications.

3. Build the website using the finalized content.

4. Connect the website to a structured content system so updates automatically flow into both the website and the PDF.

5. Implement automatic PDF regeneration after the content structure has been finalized.
